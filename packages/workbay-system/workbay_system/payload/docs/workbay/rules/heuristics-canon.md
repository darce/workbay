# Heuristics canon — consumption pointer

WorkBay does not vendor or project heuristics. Consume them **verbatim** from
the public repository:

**https://github.com/darce/heuristics-canon**

## Rules of use

- Always pull **latest**. Versions are **never pinned** — do not pin a tag,
  commit, or date.
- Cite stable **rule ID**s (for example `RES-02`, `AGT-21`). Never cite a
  version or date as authority. Check that an ID exists in canon before citing
  it: a plausible-looking ID canon does not define is a fabricated citation, and
  nothing in this tree will catch it for you.
- Apply and check heuristics by judgment during implementation and review.
  There is no deterministic guard over heuristics references.
- In network-less sandboxes, inline the needed rules into the dispatch brief
  rather than inventing a local projection.

Canon is not transformed, projected, or mirrored into this tree. This file is
only a pointer.
